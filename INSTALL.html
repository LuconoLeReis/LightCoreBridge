New to LightCore?

First-time install

Set it up once. Keep using this folder.

  1. Create a folder called LightCore

    Put it somewhere you will keep, such as Documents or your Desktop. You choose the location.

  2. Save the ZIP in LightCore

    Click Download LightCore Bridge. Save LightCore-Bridge.zip inside that folder. If it lands in Downloads, move it into LightCore.

  3. Extract into that same folder

    Right-click the ZIP and choose Extract All. Set the destination to your existing LightCore folder, then click Extract.

    Windows may suggest a new folder named LightCore-Bridge. Change that destination to LightCore.

    You should now see manifest.json and the other files directly inside LightCore, beside the ZIP.

  4. Load LightCore into Chrome

    Open Chrome's Extensions page:

    chrome://extensions

    Turn on Developer mode at the top right. Click Load unpacked, select your LightCore folder, then click Select Folder.

  5. Open your character sheet

    Open or refresh D&D Beyond. The extension card in Chrome should say LightCore Bridge.

    Keep the LightCore folder. Chrome still needs the extracted files after installation.

Next time, use the update steps. You only need Load unpacked for the first installation.

Already installed?

Update LightCore

Same folder. Same extension. Your settings stay.

  1. Keep your existing installation

    Finish any pending rolls. Use the same folder Chrome already loads. If you followed this guide, that is LightCore.

    Do not remove the extension, rename its loaded folder, or use Load unpacked again.

  2. Save the new ZIP there

    Click Download LightCore Bridge and save it in your LightCore folder. Replace the previous ZIP if asked.

    If Windows saves a numbered copy such as LightCore-Bridge (1).zip, use the newly downloaded copy.

  3. Extract and replace the files

    Right-click the new ZIP and choose Extract All. Set the destination to your existing installation folder.

    Click Extract, then choose Replace the files in the destination when Windows asks. Wait for extraction to finish.

  4. Reload LightCore, then refresh your sheets

    Open Chrome's Extensions page:

    chrome://extensions

    On the LightCore Bridge card, click the small circular Reload icon. Then refresh your D&D Beyond and VTT tabs.

    Use Reload on the LightCore card. You do not need to remove and reinstall it.

Installed in a folder with an older name?

Keep using that folder, even if it is called WayBeyond20. Save the ZIP in LightCore if you prefer, but extract its contents into the folder Chrome already uses. Keeping that path and the same extension installation preserves your settings.

Your settings belong to the existing Chrome installation. Replacing files and reloading keeps that installation.

A few things that make this easier

The ZIP is the download

Chrome loads the extracted folder, not the ZIP. You can keep both together in LightCore.

Chrome cannot find manifest.json?

The files are probably one folder too deep. Open LightCore and check that manifest.json is directly inside it, then select that folder in Chrome.

Already have Beyond20 enabled?

Disable a duplicate Beyond20 or WayBeyond20 extension while using LightCore Bridge so both do not handle the same roll.

TaleSpire uses a separate companion

This download installs the Chrome extension. An existing TaleSpire companion is updated separately using the TaleSpire setup guide.

This guide covers Chrome on Windows. Other browsers and operating systems may use different menus.
